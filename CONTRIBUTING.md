# Contributing

1. Open an issue first for anything bigger than a fix, so we agree on the direction.
2. Build and test the part you change: see `mac/README.md`, `android/README.md` or `extension/README.md`.
3. Keep user-facing text short and plain. Update the matching page in `site/src/content/docs/` when behaviour changes.
4. One change per pull request, with the tests that cover it. CI must pass.

Bug reports are easiest to act on with your phone model, Android version, macOS version and what you saw. Use the issue forms.
