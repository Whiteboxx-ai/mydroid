---
title: Keep it running
description: Stop Android from closing Mydroid in the background.
---

Some phones close background apps to save battery. Two settings stop that.

## 1. Battery

Tap **Fix** on the Mydroid home screen when it says *Android may pause Mydroid*, then choose **Allow**. Some phones save this a moment later; the warning clears by itself.

## 2. Your phone's own app-closing setting

Phone makers add their own. Open the matching one:

| Phone | Where |
|---|---|
| OnePlus, OPPO, realme | Settings → Apps → Mydroid → Battery usage → **Allow background activity**; also **Auto launch** on |
| Xiaomi, Redmi, POCO | Settings → Apps → Manage apps → Mydroid → **Autostart** on, Battery saver → **No restrictions** |
| Samsung | Settings → Battery → Background usage limits → **Never sleeping apps** → add Mydroid |
| Pixel and others | The battery step above is usually enough |

Menu names change between versions. Mydroid opens the right screen when it can.

Also lock Mydroid in the recent-apps view (long-press its card → **Lock**) so the phone doesn't swipe it away.
