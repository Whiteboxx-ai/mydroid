---
title: Keep it running
description: Stop Android from closing Mydroid in the background.
---

Some phones limit what apps can do with the screen off.

## Background activity

If Mydroid says **Background activity restricted**, tap **Fix** to open its App info. Open **Battery** or **Battery usage** and allow background activity.

## If sync stops while the screen is locked

On your phone, open **Mydroid → Settings → Battery optimization**. Tap **Open settings**, find Mydroid in Android’s list and choose **Don’t optimize** if available. Mydroid shows **Exempt** when Android confirms this setting. It can increase battery use.

## If Mydroid still disconnects

Check the setting for your phone. Menu names vary by model and Android version.

| Phone | Where |
|---|---|
| Google Pixel | Open **App info → App battery usage** and turn on **Allow background usage**. [Pixel Help](https://support.google.com/pixelphone/answer/7015477) |
| Samsung | In **Battery → Background usage limits**, remove Mydroid from **Sleeping apps** and **Deep sleeping apps** if listed. Add it to **Never sleeping apps** or **Never auto sleeping apps**. [Samsung Support](https://www.samsung.com/us/support/answer/ANS10003442/) |
| Xiaomi, Redmi, POCO | Search Settings for **App battery saver**, select Mydroid and choose **No restrictions** if available. If Mydroid also fails to reconnect after a restart, look for **Background autostart**. [Xiaomi battery help](https://www.mi.com/global/support/faq/details/KA-538010/) · [Redmi autostart help](https://www.mi.com/global/support/faq/details/KA-497677/) |
| OnePlus, OPPO, realme | Search Settings for **App battery management**, select Mydroid and turn on **Allow background activity**. If reconnecting after a restart is also a problem, look for **Auto launch**. [OnePlus steps](https://consumer.huawei.com/ph/support/content/en-us15848666/) · [OPPO steps](https://consumer.huawei.com/ca/support/content/en-us15848664/) · [realme Support](https://www.realme.com/global/support/faq) |
| vivo, iQOO | Search Settings for **Background power consumption management** or **Background high power consumption**, and allow it for Mydroid if available. [vivo and iQOO steps](https://consumer.huawei.com/en/support/content/en-us15977902/) |
| Huawei, Honor | Search Settings for **App launch**. Select **Manage manually** for Mydroid and enable **Run in background**. [Huawei Support](https://consumer.huawei.com/en/support/content/en-us00428704/) · [Honor steps](https://consumer.huawei.com/en/support/content/en-us15848660/) |
| Motorola | If your model has **Battery → Background app use**, check whether Mydroid can be set to **Always allow**. [Motorola user guide](https://en-us.support.motorola.com/app/answers/detail/a_id/180142/) |
