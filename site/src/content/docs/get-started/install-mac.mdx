Mydroid runs on Apple silicon and Intel Macs with macOS 14 or later.

1. Press **⌘ Space**, type **Terminal**, and press **Return**.
2. Copy the command below, paste it into Terminal, and press **Return**.

<InstallCommand />

The installer checks the download, puts Mydroid in Applications, and opens it. Look for Mydroid in the menu bar and a pairing QR code.

## Install from the ZIP

Download [Mydroid-mac.zip](https://github.com/Whiteboxx-ai/mydroid/releases/latest/download/Mydroid-mac.zip), unzip it, and drag Mydroid to Applications.

If macOS blocks the first launch, open **System Settings → Privacy & Security** and choose **Open Anyway** for Mydroid. Use the [release checksums](https://github.com/Whiteboxx-ai/mydroid/releases/latest/download/SHA256SUMS) to check the file before opening it.
